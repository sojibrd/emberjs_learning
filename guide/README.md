# guide — source and licence

The 58 rule files in this folder, and `_sections.md`, are an unmodified copy of the
`rules/` folder of the **ember-best-practices** agent skill (version 1.0.0).

- **Upstream:** https://github.com/ember-tooling/agent-skills — `skills/ember-best-practices/`
- **Author:** Ember.js Community — as declared in the skill's `SKILL.md`
- **Licence:** MIT — as declared in the skill's `SKILL.md` (`license: MIT`). On
  2026-10-11 the upstream repository carried no separate `LICENSE` file, so that
  declaration is the only licence text there is to reproduce.
- **Copied:** 2026-10-11, from an installed copy of the skill; the upstream folder
  listed the same 58 rule files that day.

Nothing here is written by the owner of this repository. The day-by-day plan in
`docs/` and the site code are separate work and only quote rule titles.

Do not edit these files. A rule that changes upstream is replaced by a fresh copy,
so the text on the site always matches the source.

`_template.md` from the source is left out — it is a placeholder, not a rule.
